# Logo e Icono BackBone

Este repositorio contiene los recursos oficiales de logo e icono para la comunidad y semillero de investigación Backbone. Los recursos están disponibles en múltiples formatos y estilos para adaptarse a diversos casos de uso.

## Recursos Disponibles

Los recursos están organizados en la siguiente estructura:

### Recursos de Icono (Icon/)

Versiones simplificadas solo del icono, adecuadas para favicons, iconos de aplicaciones y visualizaciones compactas.

- **Estilo Filled (Relleno)**

  - Versión Oscura: PNG | SVG
  - Versión Clara: PNG | SVG

- **Estilo Outlined (Contorno)**
  - Versión Oscura: PNG | SVG
  - Versión Clara: PNG | SVG

### Recursos de Logo (Logo/)

Versiones completas del logo con texto en formato horizonal, adecuadas para encabezados, documentación y materiales de marketing.

- **Estilo Filled (Relleno)**

  - Versión Oscura: PNG | SVG
  - Versión Clara: PNG | SVG

- **Estilo Outlined (Contorno)**
  - Versión Oscura: PNG | SVG
  - Versión Clara: PNG | SVG

## Guías de Uso

### Formatos de Archivo

- **SVG:** Formato vectorial, ideal para uso web y escalado a cualquier tamaño sin pérdida de calidad
- **PNG:** Formato raster con transparencia, adecuado para la mayoría de aplicaciones

### Variaciones de Estilo

- **Filled (Relleno):** Versión sólida del logo/icono, mejor para tamaños más pequeños y necesidades de alto contraste
- **Outlined (Contorno):** Versión de líneas, ideal para un peso visual más ligero y ciertos contextos de diseño

### Versiones de Color

- **Oscura (Dark):** Versión negra para uso en fondos claros
- **Clara (Light):** Versión blanca para uso en fondos oscuros

### Eligiendo el Recurso Adecuado

- Use la versión de **Icon** cuando el espacio sea limitado
- Use el **Logo** completo cuando la marca necesite ser claramente identificada
- Elija **SVG** para aplicaciones web y cualquier lugar donde se pueda necesitar escalado
- Elija **PNG** para aplicaciones donde el soporte vectorial sea limitado

## Contribuciones

Damos la bienvenida a contribuciones para mejorar nuestros recursos de marca. Por favor, siga estas pautas al proponer cambios:

### Flujo de Trabajo para Contribuciones

1. Haga un Fork del Repositorio
   - Cree su propio fork del repositorio para trabajar en sus cambios
2. Cree una Rama de Características
   - Cree una rama con un nombre descriptivo para sus cambios
     ´´´
     git checkout -b asset/nombre-descriptivo-de-su-cambio
     ´´´
3. Realice Sus Cambios
   - Al agregar nuevos recursos, siga la convención de nomenclatura y estructura de directorios existente
   - Asegúrese de que todos los nuevos recursos estén disponibles tanto en formato SVG como PNG
   - Para modificaciones a recursos existentes, mantenga la consistencia con el estilo actual
4. Pruebe Sus Cambios
   - Verifique que los recursos nuevos o modificados se muestren correctamente en varios contextos
   - Compruebe que los archivos SVG estén correctamente optimizados y se rendericen adecuadamente
5. Envíe un Pull Request
   - Suba sus cambios a su fork
   - Envíe un pull request al repositorio principal
   - Incluya una descripción clara de los cambios y su propósito
   - Agregue capturas de pantalla de antes/después si corresponde

## Pautas de Diseño

Al crear o modificar recursos, por favor adhiérase a lo siguiente:

- Mantenga la identidad visual central de la marca Backbone
- Asegúrese de que los recursos estén optimizados para sus casos de uso previstos
- Siga prácticas de diseño estándar para accesibilidad y visibilidad
- Pruebe los recursos tanto en fondos claros como oscuros
